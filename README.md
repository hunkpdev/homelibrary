# homelibrary
Web application for managing a household's physical book collection — track locations,
statuses, and loans. Built with Java 21 / Spring Boot on AWS Lambda, React + TypeScript
frontend, PostgreSQL on Neon. Personal learning project focusing on AWS serverless architecture.
